# Соответствие требованиям ТЗ

Документ сверяет исходное задание (разделы 1–11) с кодом. Там, где реализация
отличается от буквы задания, это указано явно — вместе с решением заказчика или
причиной.

Обозначения: **да** — реализовано и покрыто тестом; **иначе** — реализовано с
отличием; **частично** — работает, но не всё; **нет** — не реализовано.

---

## 1. Стек и среда

| Требование | Статус | Где |

| Секреты вне репозитория и web-root | **да** | `config.py` (только env), `.gitignore`, runbook §1 |
| Бэкапы через scheduled task | **да** | `flask daily`, `ops.backup_registry` |
| Только проверенные библиотеки | **да** | argon2-cffi, PyNaCl, cryptography, pyotp, Flask-WTF, Flask-Limiter, nh3 (+ libsodium.js вендорится, D-1) |

## 5. Криптосхема

| Требование | Статус | Где |
|---|---|---|
| voter_key = Argon2id(нормализованные ФИО+ДР+документ, salt=pepper) | **да** | `registry/identity.py`: NFKC, casefold, ё→е, гомоглифы, `\x1f` |
| Исходные данные сразу уничтожаются | **да** | не сохраняются вовсе |
| Бюллетень шифруется публичным ключом опроса (sealed box), JS с нашего домена, хэш публикуется | **да** | `static/js/*`, `vendor/*`, `assets.py` → `poll.start.js_manifest_hash` |
| Payload {poll_id, district_id, choice, random_padding} | **да** | `ballots/payload.py` (фиксированный размер + pad) |
| Приватный ключ офлайн, публикуется после закрытия | **да** | `scripts/poll_keygen.py`, `polls/lifecycle.publish_private_key` |
| Shamir (опционально) | **нет** | `--shamir` отказывает явно; docs/04 Q5 |
| Секрет избирателя ≥128 бит, показывается один раз | **да** | `randomSecret` (256 бит), Crockford, один показ |
| Секрет по желанию из кодового слова + poll_id (Argon2id, проверка надёжности) | **да** | `deriveSecretFromPassphrase` (libsodium sumo) + Python-зеркало, паритет проверен тестом |
| ballot_id = HMAC(secret, poll_id) | **да** | JS + Python, один вектор |
| Переголосование до закрытия | **нет (D-2)** | решение заказчика: связи «человек ↔ ballot_id» нет; цена описана в docs/01 T7 |
| Журнал = SHA-256(prev_hash ‖ canonical_json(record)) | **да** | `audit/chain.py`, `scripts/verify.py` (независимая реализация) |
| Голова журнала публична, экспорт для внешнего канала | **да** | `/transparency/head`, `flask checkpoint`, `.sig` |
| Корень Меркла допущенных на старте + число по округам | **да** | `polls/eligibility.py`, `poll.start` |
| Ежедневный экспорт ballot_box + audit_log, подпись Ed25519 | **да** | `ops.export_public`, `/transparency/export/...` |
| Реестр — отдельный шифрованный бэкап | **да** | `ops.backup_registry` (AES-256-GCM, ключ офлайн) |
| Архитектура допускает слепые подписи (этап 2) | **частично** | места расширения описаны (docs/02 §2.4.10), код этапа 2 не написан |
| Честно сказать, что анонимность MVP — политика, а не криптография | **да** | docs/01 §1.4, docs/05 D-2, `/how-it-works` |

## Итог

Реализовано: всё, кроме явно перечисленного ниже. Отклонения приняты заказчиком
(D-2, D-3, D-4) или вызваны отсутствием утверждённой библиотеки (Markdown).

**Не реализовано и не замаскировано:**

1. **Переголосование** — решение D-2; цена описана в docs/01 T7 и `/how-it-works`.
2. **Загрузка документов** — решение D-3; верификация по одноразовому коду.
3. **Shamir** — скрипт отказывает, docs/04 Q5.
4. **Слепые подписи (этап 2)** — только места расширения и документация.
5. **Полная миграция шаблонов на каталог строк** — механизм готов, тексты в
   auth/admin остались внутри шаблонов.
6. **Миграции схемы** — `flask init-db` создаёт схему, но не обновляет существующую;
   для изменения нужен новый инстанс или ручной `ALTER` (runbook §2).
7. **`/verification/withdraw`, `/accessibility`** — заявка отзывается истечением,
   отдельной страницы доступности нет.
