# M10 — демо-режим и сквозной сценарий

Статус: реализовано. Ссылки: [docs/05 D-3](../05-decisions.md), docs/02 §2.10.

## Что входит

| Файл | Роль |
|------|------|
| `fairvote/demo.py` | синтетическая федеральная кампания: админ, избиратели, смешанный опрос, голоса |
| CLI `demo-seed` | одна команда для стенда |
| `tests/test_demo.py` | сквозной сценарий и офлайн-проверка |

## Что создаётся

* админ `admin` с паролем `demo-parol-2026` (роль `admin`, TOTP можно включить тут же);
* по 12 избирателей в двух одномандатных округах (Москва и Петербург), пароль тот же;
* опрос со смешанной системой: партийный список (3 партии + «против всех») и по два
  кандидата в каждом округе; порог анонимности 2; старт — час назад, конец — через неделю;
* публичный ключ опроса зафиксирован, снапшот допущенных посчитан, 12 голосов уже
  подано и сброшено в батч;
* приватный ключ демо-опроса лежит в `instance/demo-keys/poll-<id>.json`.

## Обоснования

1. **Демо-ключ на диске — осознанное исключение.** В проде приватный ключ не должен
   появляться на сервере до закрытия (D-4). Здесь без него нельзя пройти сценарий
   «закрыть → опубликовать → пересчитать» на стенде. Поэтому: файл помечен
   `DEMO ONLY`, а `demo.seed` отказывается работать вне `DEMO_MODE`.
2. **Избиратели создаются через штатный сервис.** Это медленнее прямых вставок
   (Argon2id на каждого), но демо повторяет настоящий путь: те же проверки, тот же
   `voter_key`, та же запись в журнал.
3. **Сквозной тест — главный результат модуля.** Он проходит весь путь: seed →
   вход избирателя → страница бюллетеня → закрытие → публикация ключа → пересчёт →
   выгрузка артефактов → `scripts/verify.py` → `RESULT: OK`.

## Как запустить стенд

```bash
export FV_DEMO_MODE=1 FV_INSTANCE_DIR=$PWD/instance
# четыре секрета по 32 байта base64 (см. README)
flask init-db
flask demo-seed
flask run            # или деплой на PythonAnywhere
```

Закрыть и посчитать демо-опрос:

```bash
flask poll-close <poll_id>
flask poll-publish-key <poll_id> --key-file instance/demo-keys/poll-<poll_id>.json
flask poll-tally <poll_id>
flask export-poll <poll_id> --out /tmp/verify-me
python scripts/verify.py --audit /tmp/verify-me/../audit.jsonl \
  --ballots /tmp/verify-me/ballots.jsonl \
  --poll /tmp/verify-me/poll.json --poll-key /tmp/verify-me/key.json
```
