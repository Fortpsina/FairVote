# M3 — опросы, контент и обязательства по допущенным

Статус: сервисный слой и обязательства готовы; публичные страницы опросов — следующий
шаг (вместе с M4, где появляется бюллетень). Ссылки:
[docs/02 §2.3.2, §2.4.3, §2.5.2](../02-architecture.md).

## Что входит

| Файл | Роль |
|------|------|
| `fairvote/polls/content.py` | Markdown-подмножество → HTML, затем `nh3` с белым списком |
| `fairvote/polls/eligibility.py` | Меркл: листья, корни округов, агрегатный корень, пути включения |
| `fairvote/polls/models.py` | SQLAlchemy Core-таблицы polls-хранилища |
| `fairvote/polls/service.py` | создание/правка, контесты и варианты, ключ, детерминированный старт |
| `fairvote/registry/service.py` | `eligible_voters(...)` — снапшот с отсечкой по времени |

## Обоснования

### 1. Markdown-подмножество вместо парсера Markdown

Утверждённый список библиотек не содержит Markdown-парсера, а любой парсер — это
парсер недоверенного ввода. Поэтому рендерится **явно описанное подмножество**
(заголовки `##`/`###`, абзацы, списки, `**жирный**`, `*курсив*`, `` `код` ``, ссылки,
цитаты): сначала всё экранируется, потом вставляются только разрешённые теги, а
`nh3` с белым списком работает вторым, независимым барьером.

Ссылки вынимаются **до** экранирования: иначе `https://example.org/<script>` превращался
в `&lt;script&gt;` и проходил проверку схемы (поймано тестом). Схемы — только
`http`, `https`, `mailto`; `javascript:`, `data:`, `file:`, относительные и
протокол-относительные (`//evil`) отбрасываются, текст остаётся текстом.

Тесты проверяют не «строка исчезла» (payload обязан быть видимым текстом), а
инвариант: **в выводе только разрешённые теги и ни одного `on*`-атрибута**.

### 2. Дерево Меркла: promotion, а не дублирование

Нечётный узел поднимается без изменений (RFC 6962-стиль). Из-за этого форма дерева
не выводится из одного пути, поэтому `verify_inclusion` принимает `count` — число
допущенных в округе, которое и так публикуется в обязательстве. Без него проверка
ломается на нечётных размерах (3, 5, 6, 7, 9 — все покрыты параметризованным тестом).

Дубликаты ключей **не** дедуплицируются: повторный ключ — это второй лист, и корень
честно меняется. Дедупликация скрыла бы ошибку регистрации.

### 3. Снапшот с отсечкой по `starts_at`

`eligible_voters(..., cutoff=poll.starts_at)` берёт только тех, у кого
`verify_decided_at <= starts_at`. Поэтому ленивый старт (первый запрос через час)
даёт тот же корень, что и пунктуальный: тест `test_lazy_start_produces_the_same_root`
сравнивает два опроса, у одного из которых голосующий подтверждён уже после старта.

### 4. Старт идемпотентен по журналу

`commit_start` сначала проверяет `audit.has_entry(kind="poll.start")` и только потом
пишет запись; корень детерминирован, поэтому повторный вызов не создаёт вторую запись
и не меняет обязательство. Запись в журнал идёт **до** обновления опроса: если процесс
упадёт между шагами, повтор найдёт запись и просто доведёт состояние.

### 5. Неизменяемость — три уровня

Сервис отказывает (`PollLocked`) → триггер БД (`RAISE ABORT`) → публичный
`content_hash` в журнале. Тест проверяет первые два, третий обеспечивается
`poll_revision` + записью `poll.create`/`poll.update`.

### 6. Что публикуется, а что нет

Публикуются: `(code, count, root)` по округам и агрегатный корень. **Не** публикуются
листья и пути включения — иначе `H(voter_key)` стал бы оракулом членства для любого,
кто знает паспортные данные человека (docs/01 T15, docs/04 C1).

## Проверено

`337 passed` (весь набор). По M3: 30 тестов сервиса (создание, валидация окна и
порога, санитизация описания, правка до/после старта, контесты и варианты, ссылки,
commit ключа и его неизменяемость, старт без ключа/округов/до времени, заморозка
допущенных, совпадение корня с независимым пересчётом, идемпотентность, два округа,
пустой округ) и 32 теста Меркла (детерминизм, домены, promotion, пути для 1–9
листьев, подмена листа/индекса, нечлен).

## Осталось по M3

* публичные страницы `/polls` и `/polls/<slug>` (вместе с M4: там же появляется
  конфиг бюллетеня для JS);
* ленивый `poll-start-all` из CLI и закрытие опроса (M6, вместе с бюллетенями).
