## 1. Секрет из кодового слова (ТЗ §5.3)

Задание требует: «по желанию секрет выводится Argon2id из кодового слова
пользователя + poll_id (с проверкой надёжности)».

Что сделано:

* `deriveSecretFromPassphrase(passphrase, pollId)` в браузере;
* соль = `SHA-256("fairvote/secret/v1|" + pollId)[:16]` — одинаковая для одного
  опроса и разная для разных;
* Argon2id через **libsodium `crypto_pwhash`**: `OPSLIMIT_INTERACTIVE` (2),
  `MEMLIMIT_INTERACTIVE` (64 MiB), `ALG_ARGON2ID13`, 32 байта;
* проверка надёжности: не меньше 20 символов и 4 слов; в интерфейсе прямо сказано,
  что стойкость кодового слова целиком на совести пользователя, потому что
  `ballot_id` публичен и перебирать можно офлайн;
* Python-зеркало `derive_secret_from_passphrase` — нужно инструментам проверки.

**Пришлось сменить сборку libsodium.** Стандартная `libsodium-wrappers` не содержит
`crypto_pwhash` — функция есть только в **sumo**. Поэтому вендорится
`libsodium-sumo` + `libsodium-wrappers-sumo` (0.7.15). Цена: core вырос с 658 КБ до
960 КБ; D-1 обновлён.

**Паритет проверен байт в байт.** `tools/check_passphrase.js` считает соль через
WebCrypto и Argon2id через ту же сборку libsodium, что отдаётся браузеру; тест
сравнивает результат с Python. Один и тот же вход даёт одинаковые 32 байта — иначе
избиратель, пересчитавший секрет «другим способом», не нашёл бы свой бюллетень.

## 2. Подключаемый провайдер верификации (ТЗ §6)

`fairvote/registry/providers.py`:

```python
class VerificationProvider(Protocol):
    name: str
    def request(self, store, user, *, now=None) -> tuple[str, verification.Request]: ...
```

* `ManualProvider` — оставляет заявку ожидающей, решение вносит человек
  `flask verification-decide`;
* `DemoProvider` — сразу одобряет (только `DEMO_MODE`);
* `for_settings(settings)` выбирает провайдера по конфигурации — **демо-провайдер
  невозможен вне демо-режима** (fail closed, тест).

Веб-слой больше не выбирает метод в форме: кто проверяет — решает конфигурация, а не
заявитель. Внешний IdP или проверка электронной подписи подключаются за тем же
протоколом.

## 3. Редактор логов (ТЗ §8)

`fairvote/security/redact.py`: фильтр, который до форматирования вычищает из сообщения
и аргументов IPv4/IPv6, e-mail, длинные hex- и base64-токены. Подключается к
`app.logger`, к логгеру `werkzeug` и к `fairvote`. Тесты: юнит на шаблоны и сквозной —
полный цикл голосования не оставляет в логах `ballot_id`.

Фильтр — вторая линия: правило «не логировать PII» соблюдается в коде явно, фильтр
ловит то, что просочилось через `%s`-аргументы.
